READY FOR KICKOFF

Invalid submissions stop with an error. Existing clients receive confirmation without new resources. Only new clients continue to AI-powered kickoff preparation.

WORKFLOW 01

Client Onboarding & Provisioning

The first workflow transforms a client form submission into an organized workspace and structured project record, while validating incoming information and preventing duplicate client provisioning.

  1. 01

    Next.js / Client Portal

    Client Form Submission

    The client completes a custom onboarding form through the NovaGrowth website, providing company information, contact details, selected service, package, project goals, and relevant requirements.

  2. 02

    n8n / Webhook / JavaScript

    Receive and Validate Submission

    The website sends form data to n8n through a webhook. The workflow normalizes incoming fields, checks required information, and prepares the submission for processing. Invalid submissions receive an error response.

  3. 03

    n8n / Google Drive / Conditional Logic

    Check for Existing Client

    The workflow searches Google Drive for an existing client folder before creating resources. If the client already exists, it returns a successful existing-client response without creating duplicate folders or records.

  4. 04

    Google Drive

    Create Google Drive Workspace

    For new clients, the workflow creates a dedicated Google Drive folder to centralize project resources.

  5. 05

    Google Drive

    Generate Standardized Subfolders

    Five folders provide a consistent organization system for every client, from initial onboarding through final reporting.

    Client Workspace/
    • 01 - Onboarding
    • 02 - Strategy
    • 03 - Assets
    • 04 - Deliverables
    • 05 - Reports
  6. 06

    ClickUp

    Create ClickUp Client Record

    The workflow creates the main client record in ClickUp, organizing submitted contact details, service selection, project information, and onboarding requirements.

  7. 07

    n8n / Webhook Response

    Return Website Confirmation

    Once the new client has been provisioned, the workflow returns a successful response to the onboarding website, allowing the user to see a confirmation.

  8. 08

    n8n Workflow Orchestration

    Trigger Workflow #2

    After provisioning, Workflow #1 passes relevant client information and resource identifiers to Workflow #2 for AI-powered kickoff preparation.

WORKFLOW 02

Client Kickoff & AI Intelligence

The second workflow transforms newly provisioned client information into actionable kickoff tasks, structured AI-generated documentation, and an internal team notification.

  1. 01

    n8n

    Receive Provisioned Client

    Workflow #2 receives the newly created client’s information and resource identifiers from Workflow #1. It verifies the required fields before continuing.

  2. 02

    n8n / JavaScript

    Prepare AI Context

    The workflow organizes the client’s company information, business challenges, desired outcomes, selected service, package, and project requirements into structured context for AI processing.

  3. 03

    OpenAI / GPT-5 mini / Prompt Engineering

    Analyze Client Requirements with AI

    OpenAI GPT-5 mini analyzes the submitted information and generates a structured onboarding assessment.

    • Executive Summary
    • Client Problem
    • Desired Outcome
    • Proposed Approach
    • Project Objectives
    • Onboarding Priorities
    • Missing Information
    • Kickoff Questions
    • Recommended Actions
  4. 04

    n8n / Structured Output Parser / JavaScript

    Validate Structured AI Output

    Structured output parsing and validation logic check the AI-generated response before the workflow passes results to downstream applications.

  5. 05

    ClickUp

    Generate ClickUp Kickoff Tasks

    Validated AI recommendations become approximately five to seven actionable onboarding tasks, created in the ClickUp Operations → Onboarding list.

  6. 06

    Google Docs

    Generate AI Onboarding Brief

    The system creates a structured AI Onboarding Brief in Google Docs containing client context, business challenges, desired outcomes, proposed approach, priorities, missing requirements, and kickoff questions.

    Open the preview to scroll through the original full-document screenshot.

  7. 07

    Google Docs / Google Drive

    Organize the Generated Document

    After creating the AI Onboarding Brief, the workflow moves the Google Doc into the client’s dedicated 01 - Onboarding Google Drive folder.

  8. 08

    Slack

    Notify the Internal Team in Slack

    A structured Slack notification brings client information, AI insights, and direct links together, helping the team access important resources without searching separate applications.

    • Client information, service, package, and preferred start date
    • Client Strategy Snapshot: problem, desired outcome, and proposed approach
    • Outstanding follow-up requirements
    • Direct links to the Drive workspace, AI brief, and ClickUp onboarding tasks
